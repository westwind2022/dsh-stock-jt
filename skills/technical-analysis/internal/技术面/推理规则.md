**定位：** 技术面研判的可操作规则，产出**供人决策的论据**（非信号、非分数），统一用架梯动力学语言（符号体系见本 skill §符号体系）——买点唯一 = 架梯第三腿（E 点）。

## 0. 读法与口径声明（先读）

1. **一套语言**：本文与机器输出、人做决策共用同一套词汇（闸门 / 架梯·前腿 / 架梯·后腿 / 第三腿 / 区间套 / 架梯套 / 成坡 / 挂坡 / 端子 / E 点），以本 skill 符号体系为准，不做翻译（架梯动力学「同一套语言是硬约束」）。
2. **先骨架后力气**：先读结构（`zhongshu` + 笔段路 prev/next 索引）定位「在哪」，再读量化因子（`bi_frac` 四列）回答「多强」，落到「架梯第三腿」买点「在哪做」。
3. **双轨制**：结构计算、信号检出归 chanlun_dll；本 skill 只解读、不重算、不改结构。
4. **阈值不硬编码**：阈值引用技术分析领域经验值（文末「阈值来源表」，出处已脱敏）；判断方法以注入点文件「当前实现」为准，规则不重复抄写。
5. **研判结论是论据**：每条规则结论是「论据 + 置信度」，写入 reasoning_layers，不下「可做/不可做」、不作 1-100 评分。

## 第〇部分：操作流程层（主轴 + 审美 + 编排锚）

> 分工红线：DLL 做二值检出（过滤出信号池，不排序）；LLM 在信号池内做相对优选排序 + 走势解读。

### 〇.1 切入点主轴（四步）+ 多周期分工

| 步 | 隐喻 | 操作 | 字段 |
|----|------|------|------|
| 1 先定基准点 | 翻台 | 读最近结构分型作锚（多为左侧段底分型，最大结构是笔时为笔） | `bi_frac.frac_type/frac_idx/frac_price/frac_date` + `duan_frac.frac_idx` |
| 2 左验结构 | 摆桌 | 沿 `prev1/2/3_frac_idx` 左验（吸筹中枢 vs 趋势中枢） | `zhongshu` + `bi_frac.prev1/2/3_frac_idx` |
| 3 右捕时机 | 上菜 | 沿 `next1/2_frac_idx` 右捕介入时机 | `bi_frac.next1/2_frac_idx` + `frac_price` |
| 4 判新鲜度 | 判失效 | 介入点距最新 K 线 ≤ N 根（默认 2） | `meta` + `bi_frac.frac_date` |

**多周期分工（势 · 外在约束，架梯动力学 §3.4）**：**月线看空间（界壁 = 布林线上下轨）、周线看方向（60 线角度）、日线看位置、30 分钟看买点，顺大逆小、高空低多、所见即所得**。共振在集合运算层做交集，各周期独立检出、不合并底层数据。

### 〇.2 审美层（极性加权排序 + 位置反转）

> DLL 的多维共振 = 集合交集（二值检出）答「有没有」；LLM 的审美共振 = 极性加权（相对排序）答「好不好、排第几」。审美是排序论据，不做 0/1 信号、不做 1-100 分、不覆盖检出集合。

**（1）统一极性表**：三态映射 好 = +1 / 中性 = 0 / 坏 = -1（完整见 `config/polarity_table.json`）。
**（2）位置反转**：「中性·看位置」因子（`macd_area`/`vol_sum`/`pct_change`/`break_type` 真跌破/`zsPsVolExpand`）先定位置再取极性（完整见 `config/polarity_table.json` reversal）。
**（3）审美强度 = Σ(w_i × 极性_i)**：极性 ∈ {+1, 0, -1}，w_i 默认 1.0，可调（`config/weight_table.json`）。用于信号池内相对排序，非 DLL 集合交集。

## 第一部分：势（周期分工 · 外在约束）

> 势回答「值不值得分析」，即架梯动力学三层述求的第一问（空间 / 方向 / 位置）。

### 规则 1 · 月线空间（势 / 月线成色）

- **回答**：值不值得分析 · 空间（静态势能）。
- **判定**：价格处于月线界壁（布林线上下轨 = 围绕价值的大周期波动区间）的哪个边界——高势能区 / 低势能区 / 平衡区。判断方法锚 `结构/势/月线/成色.md`。
- **研判结论**：「月线空间 {打开 / 砸出 / 平衡}（锚 `kline.ma20/ma60` 界壁近似）」——势能高低是空间论据，不产出买点，供多周期共振与「值不值得分析」判断。

### 规则 2 · 周线方向（势 / 周线成色）

- **回答**：值不值得分析 · 方向（动态势能）。
- **判定**：周线 60 线角度定涨潮 / 落潮，高低点序列定力度（加速 / 匀速 / 衰竭）。判断方法锚 `结构/势/周线/成色.md`。
- **研判结论**：「周线方向 {涨潮 / 落潮}，力度 {加速 / 匀速 / 衰竭}（锚 `kline.ma60` 斜率 + `bi_frac.frac_price` 高低点序列）」——方向论据，供「值不值得分析」判断。

## 第二部分：骨架（阴阳鱼 · 三闸门 · 端子 · 第三腿）

> 骨架回答「值不值的等 / 现在等什么」。检查序 ↔ chanlun_dll 对应（架梯动力学 §4.5）：坐标 = 基准点定位器、刻度 = 介入器 36 反包回调、成色 = 过滤器 21/22、右侧 = 发射跟踪。机器产已发生事实，买卖决策归人。

### 规则 3 · 阴阳鱼（区间套 × 架梯套 递归演化）

- **回答**：跌完了吗 / 涨起来了吗（趋势的生死）。
- **判定**：区间套（旧趋势**衰竭**·背驰）与架梯套（新趋势**新生**·架梯）首尾相接——区间套锁定的「背驰拐点」正是架梯·前腿的起点。三条递归规则：**新生**（大区间套 + 小架梯套）、**发展**（大架梯套 + 小区间套）、**方向选择**（架梯套长大到与区间套同级别）。
- **研判结论**：「当前处 {新生 / 发展 / 方向选择}：区间套 {衰竭确认} + 架梯套 {新生确认}」——这是「在哪」的动力学骨架结论，供后续闸门 / 买点规则引用（架梯动力学 §3）。

### 规则 4 · 闸门 1 成坡（架梯·前腿）

- **触发条件**：沿 `bi_frac.prev/next_frac_idx` 定位架梯·前腿（向上笔，`frac_type` = top）。
- **判定关系**：
  1. **60 线上翘**（坐标）：`kline.ma60` 斜率向上（最近 N 根 `ma60` 递增，N 默认 3；前置行 `ma60=0.0` 需过滤）；
  2. **过前高**（坐标）：前腿 `bi_frac.frac_price` > 前一同向笔 `frac_price`（沿 `prev2_frac_idx` 取）；
  3. **前腿成色**（注入点）：前腿堆量口径——锚 `结构/形/架梯套/成色.md`。
- **研判结论**：「闸门 1 成坡 {成立/不成立}：60 线上翘 {是/否}、过前高 {是/否}、前腿成色 {足/不足}」——成坡是架梯分型第一腿，不成坡则无梯可架，等下一次前腿。

### 规则 5 · 闸门 2 挂坡蓄势（架梯·后腿）

- **触发条件**：定位架梯·后腿（向下笔，`frac_type` = bottom，紧邻前腿之后的首次回调）。
- **判定关系**：
  1. **挂坡不破**（坐标）：后腿 `bi_frac.frac_price` ≥ 同 `frac_idx` 的 `kline.ma60`；
  2. **回调形态**（坐标）：简单回调（一笔到位）vs 复杂回调（箱体，以 `zhongshu` 为载体：`zg` 上沿 / `zd` 下沿 / `range_ratio` 窄幅 / `zs_start~end_idx` 时间跨度）；
  3. **供给枯竭**（成色）：逐次回踩缩量递减——口径锚 `结构/形/架梯套/成色.md`；
  4. **回调深浅**（成色）：后腿回撤分位 0.382 浅 / 0.5 / 0.618 深（三点自算）——口径锚 `结构/形/架梯套/成色.md`。
- **漏检留痕（G4）**：横盘未达 5 分型、`zhongshu` 无行 → 输出「缺结构·置信度下调」，不自建箱体（守「只解读不计算」红线）。
- **研判结论**：「闸门 2 挂坡蓄势：{简单回调/复杂回调}，挂坡 {破/不破}，供给枯竭度 {递减实值}，回调深浅 {0.382/0.5/0.618}」——蓄力是回调形态、非突破结果，归属上一轮小级别。

### 规则 6 · 闸门 3 点火 + 右侧发射状态（第三腿）

- **触发条件**：架梯分型（规则 4+5）完成后，定位第三腿（重新向上突破的笔）。
- **判定关系（触发侧，机器）**：
  1. **真突破**（坐标）：`bi_frac.break_type` = `breakout_valid`；
  2. **放量**（成色）：口径锚 `结构/形/第三腿/成色.md`；
  3. **不背驰**（成色）：口径锚 `结构/形/第三腿/成色.md`。
- **判定关系（右侧发射状态，机器观察已发生事实）**：
  4. **刻度位置**（刻度）：口径锚 `结构/形/第三腿/刻度.md`（六档目标位 `waveRuler_targets[k]`）；
  5. **表现**（成色）：口径锚 `结构/形/第三腿/成色.md`（空中加油 vs 努力无结果）；
  6. **止损止盈**（注入点 · 交人执行）：口径锚 `结构/形/第三腿/止损止盈.md`。
- **研判结论**：「闸门 3 触发 {是/否}：真突破 {break_type 实值}、放量 {vol_sum 实值}、不背驰 {是/否}；右侧发射：刻度 {第 k 档}、表现 {空中加油/努力无结果}」——成功/失败结果归人，机器只产已发生事实。

### 规则 7 · 架梯分型定性（闸门 1+2 合成）

- **触发条件**：规则 4（成坡）与规则 5（挂坡）同时成立。
- **判定关系**：架梯分型 = 架梯·前腿 + 架梯·后腿两腿 + 过前高 + 60 线上翘（趋势定性）；此时第三腿尚未发生 → 拉升前介入点。
- **研判结论**：「架梯分型 {定性成立/不成立}：两腿 {齐/缺}、过前高 + 60 线上翘 {是/否}；若成立则 N 字型尚未走完（缺第三腿），处拉升前」——定性先于定量（架梯分型两腿定性，N 字型三腿定量）。

### 规则 8 · 端子（第三腿起步第一棒）

- **回答**：现在能不能做 · 入场（第三腿起步第一棒，只对买入负责）。
- **判定**：端子成色确认 = 入场信号，同时终结本轮架梯套 / 区间套的递归分析（递无可递）。判断方法锚 `结构/形/端子/成色.md`（当前实现 = 两根大阳线起步，可换反转 K / 一阳穿多线）。
- **临场操作**：小级别递归「递无可递」时，只能在架梯分型的前腿介入，以端子成色确认强势起步，作为架梯套递归的终结。
- **研判结论**：「端子成色 {确认/未确认}（锚 `kline` 阳线实体 + `bi_frac.break_type`）」——入场论据，只对买入负责。

### 规则 9 · 区间套衰竭确认（多级别背驰共振）

- **回答**：值不值的等 · 衰竭侧（旧趋势死）。
- **判定**：多级别背驰共振（月背离 → 周背驰 → 日背驰 → 30 分背驰）。判断方法锚 `结构/形/区间套/成色.md`。
- **研判结论**：「区间套 {衰竭确认/未确认}：多级别背驰 {共振/不共振}（锚 `bi_frac.macd_area` + `bi_frac.pct_change`）」——衰竭是「值不值的等」的前提，为架梯套新生让位。

## 第三部分：买点与持仓（交人执行）

### 规则 10 · 第三腿强势起步 = 唯一买点（E 点）

- **回答**：现在等什么 / 能不能做的最终落点。
- **判定**：E 点 = 第三腿强势起步（归纳 = 本级别两根大阳线 / 演绎 = 次级别架梯成色 A⁻→E⁻）；买点 ≠ 第三腿突破（突破翻箱、盈亏比约 1:1）。判断方法锚 `结构/形/端子/成色.md` 与 `结构/形/第三腿/成色.md`。
- **研判结论**：「E 点 {触发/未触发}，第三腿强势起步 {确认/未确认}」——单一周期唯一买点（架梯动力学 §4「买点归一化」）。

### 规则 11 · 止损止盈（周期对周期 + 硬止损）

- **回答**：何时退。
- **判定**：周期对周期（日线进日线出、周线进周线出）；硬止损 = 大级别底仓跌破后腿回踩低点；止盈 = 压力位上的「努力无结果」。判断方法锚 `结构/形/第三腿/止损止盈.md`，工具交人执行。
- **研判结论**：「止损位 {启动点/后腿低点}、止盈 {努力无结果}」——机器只交付止损位事实，执行归人（架梯动力学 §5）。

### 规则 12 · 成色多级别（靠山 / 底气 / 信号，正交四问）

> 成色是对架梯分型的事实分析（非预测），须多级别配合。

| 级别 | 成色角色 | 回答的问题 | 口径 |
| :--- | :--- | :--- | :--- |
| 大级别 | 外在靠山 | 好不好 / 方向对不对 | 演绎为主（周线后腿在日线演绎成线段、看线段中笔背驰），勿漏过前高 |
| 本级别 | 内在底气 | 价格合适吗 | 归纳：量价配合、过前高、均线多头排列 |
| 次级别 | 介入信号 | 现在能做吗 | 演绎：三波五浪推动、下跌趋势背驰背离 |

- **介入约束**：要在本级别介入（配置本级别底仓），须在次级别找介入信号（时机）。
