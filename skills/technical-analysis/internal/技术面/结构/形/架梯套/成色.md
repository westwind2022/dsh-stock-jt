# 架梯套 · 成色

## 注入点定义

回答「值不值的等」的新生侧：架梯分型成色——成坡（前腿）质量 + 挂坡（后腿）质量。**架梯套是已发生的事实（新生趋势的定性结构），无交易、无止损止盈。**

## 当前实现

- **方法** = 特征〔成坡〕 ⊕ 逻辑〔条件〕；特征〔挂坡〕 ⊕ 逻辑〔条件〕
- 成坡 = 60线上翘 + 过前高 + 堆量；挂坡 = 挂坡不破 + 缩量（供给枯竭）；字段口径见 `config/feature_anchor.json`。

## 可替换点

- 成色分级：简单回调 / 复杂回调（箱体蓄力）的不同成色口径。

## 自声明

- 缠论：背驰 / 力度（成坡）。
- 威科夫：供需吸筹（挂坡缩量）。
- 波浪：均线多头（成坡）。
