# 月线 · 成色（看空间）

## 注入点定义

回答「值不值得分析」的**空间**维度：月线静态势能——价格处于哪个空间边界（高势能区 / 低势能区 / 平衡区），趋势运行的空间有多大。

## 当前实现

- **方法** = 特征〔界壁〕 ⊕ 逻辑〔条件〕
- 界壁 = 月线布林线上下轨（围绕价值的大周期波动区间）；字段口径见 `config/feature_anchor.json` → 特征〔界壁〕（布林线字段待补，暂用 `kline.ma20`/`ma60` 代用）。

## 可替换点

- 前高前低（结构极值）。
- 通道线（趋势通道）。
- 不同情况分支：高势能区 / 低势能区 / 平衡区各自判定。

## 自声明

- 波浪 / 指标系：布林线上下轨、均线带。
- 缠论：笔段路结构极值（前高前低）。
