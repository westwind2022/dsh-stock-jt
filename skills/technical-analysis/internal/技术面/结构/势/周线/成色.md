# 周线 · 成色（看方向）

## 注入点定义

回答「值不值得分析」的**方向**维度：周线动态势能——当前趋势方向（涨潮 / 落潮）与力度（加速 / 匀速 / 衰竭）。

## 当前实现

- **方法** = 特征〔方向〕 ⊕ 特征〔力度〕 ⊕ 逻辑〔比较〕
- 方向 = 周线 60 线角度（涨潮/落潮）；力度 = 高低点序列（加速/匀速/减速/背离）；字段口径见 `config/feature_anchor.json`。

## 可替换点

- DEA 角度（MACD）。
- 高低点序列（N 字型同步抬高 / 降低）。

## 自声明

- 波浪：均线系统 + 高低点序列。
- 缠论：段 / 笔方向 + 背驰。
