# 结构骨架（势与形）+ 注入点约定

技术面研判的骨架是**结构**，注入点是**结构的属性**。结构是骨架（硬编码），注入点可插拔、可自声明、可单独维护。

## 一、结构 = 骨架（硬编码，无注入点）

结构分两类：

| 类 | 结构 | 分工 | 级别 |
|---|---|---|---|
| **势** | 月线 | 静态势能（空间 / 界壁） | 大级别 |
| **势** | 周线 | 动态势能（方向） | 大级别 |
| **形** | 架梯套 | 新生趋势（成坡 + 挂坡）——已发生的事实 | 本级别 |
| **形** | 区间套 | 衰竭趋势（背驰）——已发生的事实 | 本级别 |
| **形** | 端子 | 第三腿起步**第一棒**——只对买入负责 | 次级别 |
| **形** | 第三腿 | 正在发生的持仓管理结构 | 次级别 |

结构本身含**坐标**（A/B/C/D/E 定点）与**演化语法**（三闸门递归：成坡→挂坡→点火），均硬编码，不进注入点。

## 二、注入点 = 结构属性（可插拔 + 自声明 + 单独维护）

三类注入点：

| 注入点 | 回答 | 对应角色 |
|---|---|---|
| **成色** | 多强 / 真不真 | quality |
| **刻度** | 会到哪 / 何时 | scale |
| **止损止盈** | 何时退（持仓管理，工具交人执行） | 纪律（新） |

每个结构下，涉及哪类注入点就建哪类文件；不涉及不建。

## 三、注入点文件四段式（约定）

```
# <结构> · <注入点>

## 注入点定义   ← 回答哪个决策问
## 当前实现     ← 默认实现（含锚字段 + 口径）
## 可替换点     ← 可换什么（其他流派的等价能力）
## 自声明       ← 哪些流派 × 角色能在此注入
```

## 四、两个横切（不进注入点）

- **演化**（闸门递归）= 结构骨架，硬编码。
- **记录**（级别归属留证 `frac_idx/frac_date`）= 全局纪律，每条研判结论都带。
