# 技术面研判（架梯动力学）

本章节是五维研判「技术面」的研判能力，落点属**知识层**——消费 chanlun_dll 实时算好的结构数据（投研取数模块 `scripts/struct_calc.py`：vipdoc+本地前复权主源 / MCP 备源 → `CL_ExportStruct` 五实体，字段语义同分片库六表）与量化因子，产出**供人决策的论据**（架梯分型 / 挂坡 / 强势起步 / 背驰 / 强弱），供五维共振与深度投研报告使用。

## 能力与角色

- **能力**：先读结构骨架定位「在哪」（中枢 / 笔段路连接），再读量化因子回答「多强」（量能 / 动能 / 空间 / 突破真假），综合出「架梯分型 / 挂坡 / 强势起步 / 背驰 / 强弱」研判论据。
- **角色**：技术面维度（五维之一）。
- **不是**：结构计算（归 chanlun_dll）、信号检出（归 DLL 检出层）、1-100 评分 / 榜单硬排序（禁止）。

## 符号体系（架梯动力学）

- **五定点 A/B/C/D/E**：A = 起点（前腿起点 = 背驰拐点）、B = 起点左侧同级别高点（过前高参照）、C = 高点（前腿终点 = 后腿起点）、D = 终点（后腿低点 = **挂坡点**）、E = 第三腿**强势起步**（买点）。
- **成立条件**：C > B 且 60 线首次上翘。
- **级别符号**：挂坡点 D⁺/D/D⁻（大/本/次）、强势起步 E⁺/E/E⁻；锚接 D⁺≡A、D≡A⁻，成功的 E 点永远跟在 D 点后（本级别 D→E 演绎次级别 A⁻→E⁻）。
- **买点铁律**：买点 ≠ 第三腿突破（突破翻箱、盈亏比约 1:1），= 第三腿强势起步（归纳 = 本级别两根大阳线 / 演绎 = 次级别架梯成色）。

## 结构骨架（势与形）+ 注入点

技术面研判的骨架是**结构**，注入点是**结构的属性**。结构分「势」与「形」两类，每个结构下按需挂「成色 / 刻度 / 止损止盈」三类注入点（骨架定义 + 四段式约定见 `结构/README.md`）：

| 类 | 结构 | 注入点 | 回答（技术维三层述求） |
|---|---|---|---|
| 势 | 月线 | 成色（看空间） | 值不值得分析 · 空间 |
| 势 | 周线 | 成色（看方向） | 值不值得分析 · 方向 |
| 形 | 架梯套 | 成色 | 值不值的等（新生趋势成色，已发生事实） |
| 形 | 区间套 | 成色 | 值不值的等（衰竭成色，已发生事实） |
| 形 | 端子 | 成色（第三腿起步第一棒） | 现在能不能做（入场，只对买入负责） |
| 形 | 第三腿 | 成色 + 刻度 + 止损止盈 | 买 / 持 / 卖（持仓管理） |

- **坐标**（A/B/C/D/E 定点）= 结构本身，硬编码。
- **演化**（闸门递归：成坡→挂坡→点火）= 结构骨架，硬编码。
- **记录**（级别归属留证 `frac_idx/frac_date`）= 全局纪律，每条研判结论都带。

## 研判流程（详见《推理规则.md》）

**先走主轴 → 因子清单选因子 → 审美定强弱 → 套规则**：

1. **套切入点主轴**：先定基准点 → 左验结构 → 右捕时机 → 判新鲜度（《推理规则.md》第〇部分）。
   - 多周期心法：**月线看空间、周线看方向、日线看位置、30 分钟看买点，顺大逆小、高空低多、所见即所得**。
2. **按注入点锚字段选因子**：读 `bi_frac` 四量化列 + `kline` 指标列 + `zhongshu`，只选因子读值、不打分。
3. **审美定强弱**：查统一极性表取三态极性，Σ(w×极性) 得相对排序论据（结论层，可调校）。
4. **套规则判定**：规则 1-12 逐条套用，产出研判论据（非信号 / 非分数）。

## 降级纪律

- 结构数据不可得（取数模块失败 / 主备源均不可用）→ **技术面维度降级**：简报标注「本周期结构数据缺失，技术面结论置信度相应下调」，不报错、不阻断主线；降级留痕（reports/ 标注），保证可审计。

## 红线（四条硬约束）

1. **双轨制**：只解读，不计算、不检出、不改结构。
2. **三条禁止**：不产出信号检出结论 / 不作固化量化分数（1-100 评分、榜单硬排序）/ 不覆盖原始共振检出集合。
3. **可追溯**：每条推理规则锚定 `表.字段 + 因子值`。
4. **自包含**：本 skill 不含盘符绝对路径链接。

## 输出规范

- 每条研判结论须带字段证据（如 `zhongshu.zg/zd`、`bi_frac.macd_area` 具体值）。
- 阈值一律引用领域经验值（出处见《推理规则.md》附：阈值来源表，已脱敏），不硬编码为绝对常量。
- 结论表述为「论据 + 置信度」，不作 0/1 信号。
