## 一、正例（正确研判）

### 正例 1 · 趋势背驰研判

- **场景**：某标的分片库 `zhongshu` 表有 2 个同向中枢（`zs_seq=0,1`，`enter_bi_direction` 均为 `up`，`zg/zd` 依次抬升，两中枢 `gg/dd` 波动区无重叠）→ 先判定「上涨趋势」。
- **做法（正确）**：经当前顶分型 `bi_frac.prev2_frac_idx` 定位前一同向顶分型，比较两段 `bi_frac.macd_area`（顶分型段取正值）。
- **依据**：后段 `macd_area` = 12.3 < 前段 = 28.7，且 `frac_price` 创新高（两段同向递进）。
- **结论（论据）**：「上涨趋势在 {frac_date} 处出现 MACD 动能背驰（后段 12.3 < 前段 28.7），力度衰竭，为趋势转折的候选论据，参考一卖/回抽确认」。**供人决策，未写「立即卖出信号」**。

### 正例 2 · 三类买点研判

- **场景**：盘整后出现向上离开中枢的一笔，随后回抽。
- **做法（正确）**：读 `zhongshu.zg` 取中枢区间上沿；读回抽分型 `bi_frac.frac_price` 比较是否跌破 `zg`。
- **依据**：回试低点 `bi_frac.frac_price` = 10.52 > `zhongshu.zg` = 10.30（不破中枢上沿）。
- **结论（论据）**：「向上离开中枢后回抽不破 zg（10.52 > 10.30），构成三买候选（中枢破坏/新生，其后必是更大级别中枢或上涨趋势二者之一）」。

### 正例 3 · 强弱定性（共振后压缩排序）

- **场景**：共振后长名单需压缩排序，比较 A、B 两标的谁多头结构更强。
- **做法（正确）**：分别读 `bi_frac` 四量化列 + `zhongshu` 中枢位置，做**相对比较**。
- **依据**：
  - A：`break_type=breakout_valid`（真突破）、上涨笔 `vol_sum` 为前下跌笔 ×1.35（温和放量）、回调笔缩量 ×0.6（健康）、回调 `pct_change` = 0.30（浅回调）、价格在 `zg` 上方。
  - B：`break_type=breakout_fake`（假突破）、放量下跌、回调 `pct_change` = 0.70（深回调）、价格在 `zd` 下方。
- **结论（论据）**：「A 多头结构偏强、B 偏弱，A 排序靠前」——**相对排序论据，未给 1-100 分、未覆盖原始共振检出集合**。

## 二、反例（关键坑，至少 4 个）

### 反例 1 · 把段/路当有量化列（穿透铁律）

- **错在哪**：研判段背驰时，直接读 `duan_frac.macd_area` / `road_frac.vol_sum`，或在段/路表臆造量化列。
- **为什么错**：量化因子**只挂在 `bi_frac`**（四列 `break_type/vol_sum/pct_change/macd_area`）；`duan_frac` / `road_frac` / `zhongshu` 无量化列，段/路节点索引是笔节点索引的子集。
- **正确做法**：经 `duan_frac.frac_idx`（或 `road_frac.frac_idx`）**索引平移穿透**到 `bi_frac` 同索引取量化因子；中枢经 `zs_start_idx/zs_end_idx` 等索引回 `bi_frac` 取笔量化。
- **口诀**：段/路的「力气」永远在笔上找，不凭空给段/路挂量化列。

### 反例 2 · 把研判结论写成「信号检出」或「1-100 评分」（越界）

- **错在哪**：输出「该标的构成**买点信号**，可直接买入」或「缠论强度评分 87/100，入选榜单第 3 名」。
- **为什么错**：越三条禁止红线——信号检出归 DLL 第三层、研判不作固化量化分数、榜单硬排序会覆盖原始共振检出集合。本 skill 是**知识层研判**，只产论据。
- **正确做法**：「{frac_date} 处出现趋势背驰（后段 macd_area X < 前段 Y），力度衰竭，为趋势转折候选论据，置信度中」——论据 + 置信度，决策仍交人 / 五维共振。

### 反例 3 · 混淆中枢区间（zg/zd）与中枢范围（zs_start/end）

- **错在哪**：用 `zs_start_idx/zs_end_idx`（K 线范围索引）去回答「中枢价格空间」，或用 `zg/zd`（价格带）去回答「中枢从哪根 K 线到哪根 K 线」；三买卖点判定用错字段。
- **为什么错**：`zg/zd`（区间 = 价格带）与 `zs_start_idx/zs_end_idx`（范围 = K 线区间）语义不同；三买判定必须用**价格** `zg` 与回抽 `frac_price` 比较，范围索引是时间定位。
- **正确做法**：价格空间读 `zg/zd`；K 线范围读 `zs_start_idx/zs_end_idx`；三买「回试低点 `frac_price` 不破 `zg`」。

### 反例 4 · 混淆「走势」与「走势类型」（术语消歧）

- **错在哪**：沿用部分技术派笔记口径，把「不含中枢的笔段连接」称作「走势类型」，或反过来把「趋势/盘整三类」当作「不含中枢的走势」。
- **为什么错**：该口径下「走势 = 不含中枢、走势类型 = 含中枢（趋势/盘整）」；标准口径「走势 = 泛指（打开走势图看到的）、走势类型 = 上涨/下跌/盘整三类」。同一词两义，混用会误判趋势/盘整。
- **正确做法**：**以标准口径为准**——「走势类型 = 趋势/盘整（含中枢，趋势 ≥2 同向无重叠中枢、盘整 = 1 中枢）」；其他用法仅在其语境下理解（靶点消歧 #4）。

### 反例 5（附加）· 硬编码阈值（可追溯/不硬编码红线）

- **错在哪**：在规则里写死「`macd_area` 低于 0.05 即背驰」「涨幅 >5% 即强笔」等绝对常量，当作普适判定。
- **为什么错**：缠论因子阈值无 `dict/value_line.json`（excellent/abnormal 仅财务指标）条目，绝对常量是硬编码，无法随领域经验 / 字段口径演进保鲜。
- **正确做法**：阈值引用领域经验值（如「上涨笔均量 ≥ 前下跌笔 ×1.2」，出处见阈值来源表），以**比较关系**（后段 < 前段）为主，结论表述为「论据 + 置信度」。
