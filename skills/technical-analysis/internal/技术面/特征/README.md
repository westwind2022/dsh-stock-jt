# 角色特征库

**状态：** ✅ 已组装初稿（2026-08-21，三流派特征按角色归位）
**定位：** 统一研判 skill 的**消费者侧**特征挂载点。特征库按「角色」分（坐标 / 成色 / 刻度），**不按流派分**——流派是出处标签、角色是函数签名（见 `00-概述.md` §3.1）。

## 为什么按角色，不按流派

闸门判定按「坐标 → 成色 → 刻度」顺序消费。若按流派分，则「成色」散落在缠论/波浪/威科夫三个文件里，每个闸门取成色都要横跨三个文件。按角色分后，闸门问「多强」，直接进 `成色.md`，看三个流派各贡献什么。

| 维度 | 生产者侧 | 消费者侧 |
| :--- | :--- | :--- |
| 位置 | 流派特征源（缠论/波浪/威科夫） | 本特征库（按角色：坐标/成色/刻度） |
| 理由 | 流派特征按流派组织 | 闸门按角色消费，角色跨流派 |

## 三个角色特征表

| 特征表 | 回答 | 内容（每个角色内按流派分节标注出处） |
| :--- | :--- | :--- |
| `坐标.md` | 在哪（实坐标） | 缠论（笔/段/路/中枢）★ · 波浪（前腿/后腿/第三腿）· 威科夫（交易区间/箱体） |
| `成色.md` | 多强 / 真不真 | 缠论（背驰/力度/量能/中枢质量）· 波浪（均线多头/回调深浅）· 威科夫（供需/吸筹派发/努力结果）★ |
| `刻度.md` | 会到哪 / 何时（虚坐标） | 缠论（回调比例/背驰面积比）· 波浪（黄金分割/波浪尺/时间轴）★ · 威科夫（量比/时间跨度） |

★ = 该角色下某流派的主战场（非独占）。

## 每个特征的强制标注

```
特征名 | 角色 | 流派 | 契合闸门 | 锚字段 | 阈值/口径 | 执行方（机器/人）
```

- **角色**：坐标 / 成色 / 刻度
- **流派**：缠论 / 波浪 / 威科夫（可追溯出处）
- **执行方**：机器 / 人——机器产**已发生事实**（左侧架梯质量 + 右侧发射状态），人做买卖决策；标"人"的特征照样入卡，不进机器实现清单
